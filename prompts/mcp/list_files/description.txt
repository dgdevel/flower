List one directory, filtered by a glob. Only the immediate
directory, unless the glob starts with **/ — then every
subdirectory is walked too (directories carry a trailing "/" in
the output, entries are sorted, symlinked directories are never
entered). On a project surface the path is relative to the
project's working directory ("." lists the project root) and the
listing speaks project-relative paths; on the server-wide surface
paths are absolute.
